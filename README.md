# CodeAlpha Python Internship Tasks

This repository contains Python projects completed as part of my **CodeAlpha Internship**.

## Projects

### 1. Hangman Game
A simple word-guessing game developed using Python.

**Features:**
- Random word selection from a predefined list.
- Six incorrect attempts allowed.
- Displays hidden letters.
- Checks guessed letters.
- Validates user input.
- Displays win or game-over messages.

**Concepts Used:**
- Python Lists
- Random Module
- While Loop
- For Loop
- If-Else Statements
- User Input and String Methods

**How to Run:**
```bash
python "hangman game.py"
```

### 2. Python Chatbot
A simple rule-based chatbot that interacts with users through text input.

**Features:**
- Responds to greetings.
- Answers simple questions.
- Displays the current time.
- Displays today's date.
- Exits when the user types `bye`.

**Concepts Used:**
- Python Conditional Statements
- While Loop
- User Input
- String Methods
- Datetime Module

**How to Run:**
```bash
python chatbot.py
```
